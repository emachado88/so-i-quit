# So I Quit — Rewrite to Nuxt 4 + Capacitor

> **For Hermes:** execute ticket-by-ticket (user's workflow), one at a time, top-to-bottom; TDD; one commit per ticket. Wireframe = visual contract: `docs/ui-sketch.html`.

**Goal:** Rebuild the So I Quit habit tracker (local-only) from React Native/Expo onto the proven rekup stack — Nuxt 4 SPA + Tailwind v4 + @nuxtjs/i18n + @nuxtjs/color-mode — wrapped in Capacitor for Android, with a refreshed visual design. Open a PR from branch `rewrite-nuxt-cap` once stable.

**Architecture:** **Always mobile** (user decision — no MOBILE_BUILD flag): SPA with fixed `ssr:false`, color-mode in localStorage, WebView-safe storage (localStorage behind a composable), domain logic (milestones/breakdown/format) as pure TS modules tested with Vitest. Zero backend. The web (browser) exists only for the dev loop.

**Tech Stack:** Nuxt 4.5.x · Vue 3.5 · Tailwind CSS v4 (@tailwindcss/vite) · @nuxtjs/i18n 10.x (8 locales) · @nuxtjs/color-mode 4 · @nuxt/fonts (Inter) · lucide-vue-next · Vitest + @nuxt/test-utils · Capacitor 8 (android) · @capacitor/local-notifications · @capacitor/haptics · @sentry/vue.

**Data model (ported as-is from the RN app):**

- `Habit { id, key?: 'habits.alcohol'|'habits.tobacco', name, date: string|null, savings: string|null }`
- `Milestone { id, habitId, unit, amount, reachedAt, notificationId }` — BASE_MILESTONES + yearly anniversaries (10y horizon), deterministic ids `` `${habitId}-${unit}-${amount}` ``
- `Settings { theme, language, currency, milestoneNotificationsEnabled, milestoneNotificationsPrompted }`
- Storage keys: `habits`, `milestones-v1`, `settings-v1` (localStorage)

**Palette (brand kept):** primary `#1A6B5C` · hover `#2A8F7A` · depth `#12504A` · accent `#D4922A` · subtleFill `#E5A94A` · vitality `#E8735A` · danger `#D94F4F` · light bg `#F7F6F3` / surface `#FFFFFF` / card `#F0EEEA` / text `#1C1B1A` · dark bg `#0F0E0D` / surface `#1A1918` / card `#242321` / text `#F0EEEA`.

## [DONE] Ticket 2 — Capacitor wrapper + mobile build + live reload

**Objective:** Working Android WebView from the same codebase + a dev loop with hot reload on the phone.

**Files:**

- Create: `capacitor.config.ts` (appId `com.soiquit.app` — **placeholder, confirm before Play Store release**; appName "So I Quit"; webDir `dist`; server `androidScheme: 'https'` + **dev-only**: `server: process.env.CAP_LIVE_URL ? { url: process.env.CAP_LIVE_URL, cleartext: true } : undefined` — the URL is never committed), package.json scripts, `scripts/live-reload.mjs` (**already created** — resolves LAN IP via `ip route get`, checks the dev server, injects `CAP_LIVE_URL` and runs `cap run android`; `--emulator` uses `10.0.2.2`)
- Modify: nuxt.config.ts (fixed ssr from Ticket 1 — no branches)

**Steps:**

1. `npm i @capacitor/core @capacitor/cli @capacitor/android`
2. Scripts: `mobile:generate`: `nuxt generate` · `mobile:sync`: generate + `cap sync android` · `mobile:run`: `cap run android` · `mobile:apk`: `cd android && ./gradlew assembleDebug` · `mobile:dev`: `npm run dev -- --host 0.0.0.0` · `mobile:run:live`: `node scripts/live-reload.mjs`
3. `npx cap add android` (commit `android/`; `dist/` gitignored)
4. `npm run mobile:sync`

**Phone dev loop (live reload — official v8 docs):**

- Terminal A: `npm run mobile:dev` (Nuxt/Vite dev server bound to `0.0.0.0`)
- Terminal B: `npm run mobile:run:live` (resolves the IP itself) — phone on the **same Wi-Fi**; USB debugging for the first install; emulator: `npm run mobile:run:live -- --emulator`
- Every save → Vite HMR pushes to the WebView (no native rebuild). `cap run` with `server.url` set: sync + build + install + launch.
- `cleartext: true` required (Android 9+ blocks http). If it won't connect, check the PC firewall on port 3000.

**Verify:**

- `ls android/app/build/outputs/apk/debug/app-debug.apk` after `npm run mobile:apk` (first build: Gradle downloads — background + notify)
- `npm run build` passes (SPA) and `dist/index.html` exists
- Live reload: edit a string → phone updates without rebuild
- Grep dist: `grep -rhoE 'getStorageValue\("color-mode"' dist` → `"localStorage"`

**Commit:** `feat: capacitor android wrapper + live reload dev loop`

## Risks / open decisions

- **RN data does not migrate** (native AsyncStorage ≠ WebView localStorage) — accepted; export/import JSON stays out of scope (future ticket)
- **Huge PR:** the diff deletes the whole RN app — expected for a rewrite; master keeps history until merge
- **appId `com.soiquit.app`** — placeholder; confirm before Play release
- **Exact notifications:** special app access on Android 12+; if denied → notice + inexact fallback (same pain as Expo)
- **Icons/splash:** `npx @capacitor/assets generate --android` with a 1024×1024 PNG — release ticket, not MVP
- **New i18n keys** (exact alarm hint, etc.) added to all 8 locales — the RN app had a typed shape; validate here with a script that every JSON has the same key set
